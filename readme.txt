Assignment 3: Programming for AI

How to Run the Notebook
 Open Assignment3_Programming_for_Al.ipynb in VS Code or Jupyter.
 Run all cells sequentially from top to bottom
 The generated files (dashboard.png, dashboard.pdf, and wave.gif) will automatically be saved in the outputs folder.

 What Was Hard
The most challenging part of this assignment was configuring the GridSpec layout for the Question 6 dashboard. specifically, aligning the twin y-axis for Karachi's humidity and handling the datetime conversions (pd.Timedelta) for the heat spell shading without causing overlapping text or layout errors.
